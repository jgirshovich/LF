One-time setup: link two devices

Giggles' stage and the teacher's controller talk to each other through a free Firebase project. You create it once, on your school Google account, then paste one small block of settings into each device. It stays saved on the device — you only do this once per device.

  1. On a computer, open console.firebase.google.com and sign in with jgirshovich@stanneschool.net.
  2. Click Add project, name it Laugh Floor, and click through (Google Analytics can stay off).
  3. In the project, open Build → Realtime Database, click Create database, and choose Start in test mode.
  4. Back on the project home page, click the web icon </> to add a web app, give it any nickname, and click Register app.
  5. Firebase shows a block of code with firebaseConfig in it. Copy that whole block and paste it below.

Skipping is fine for trying Giggles out on one screen. Linking can be set up later from the Link devices button.

How to run it in the classroom
  1. One-time setup (each device): tap Link devices. If linking isn't set up yet, follow the short Firebase steps — free project on your school Google account, paste the config once, done.
  2. Board device: open this page, tap Link devices, choose Stage, type the room code, tap Join room. Then AirPlay to the board and tap Full screen. Giggles fills the board with no buttons in the way.
  3. Controller iPad: same page, choose Controller, same room code, Join room. When the pill at the top turns green and says Linked, you're connected — check for that green pill before the lesson, on the school network.
  4. Voice: on the controller, tap Start microphone and allow mic access. Pick Monster, Robot, or Squeaky. Your voice comes out of the board device's speaker, changed, and Giggles' mouth follows the sound itself.
  5. Lesson items: edit the list on the controller — names, pictures, and the line Giggles says. The stage picks up the changes on its own.

Seeing the class: for the first run, use a Google Meet call. Put a spare iPad near the board facing the students, join the Meet from it and from your controller iPad, then on the board iPad turn the volume all the way down and the brightness all the way down (or face it away) so the class sees and hears nothing from it. There's no camera built into this page yet — Meet is the stand-in while we test the link.

If the pill stays yellow: the two devices can see Firebase but not each other yet — give it a few seconds, confirm both typed the same room code, and check both picked different roles. If buttons work but the live voice won't connect, the school network may be blocking direct device-to-device audio; the moves, jokes, items, and typed lines still work, and the typed lines become the voice for that lesson.

Keyboard shortcuts (handy on a MacBook controller): 1 wave, 2 jump, 3 laugh, 4/5 point, 6 smile, 7 dance, 8 confused, 9 sleepy, 0 surprise.
